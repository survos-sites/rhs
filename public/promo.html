How It Works

Two parts working together: cheap edge hardware for capture, powerful cloud for AI.

Edge

📷 Scanner Station

Runs on modest hardware at your location. Handles the physical scanning and initial processing.

  • Camera capture + live preview
  • Python-based image cropping
  • Barcode/QR detection
  • Audio transcription (Whisper)
  • Foot pedal + button triggers
  • Publishes to cloud via secure tunnel

💡 Works offline: Captures continue even if internet goes down. Queued for upload when connection restores.

Cloud

☁️ Cloud Hub

Powerful AI and storage services. Processes, enriches, and indexes your scans.

  • AI keyword generation (vision models)
  • LLM-powered descriptions & summaries
  • Sensitive content detection
  • Long-term cloud storage
  • Semantic search (Meilisearch)
  • MCP endpoints (coming soon)

🔒 Secure: Your data is encrypted at rest and in transit. Access controls and audit logs included.

Features

What each component brings to your digitization workflow.

📷

Live Preview Edge

Real-time camera feed with whole-mat and cropped views. See exactly what you'll capture before you scan.

✂️

Python Cropping Edge

Automatic document detection and cropping. Detects edges, corrects perspective, outputs clean images.

🏷️

AI Keywords Cloud

Vision models analyze images and generate descriptive keywords: "vintage photograph, family portrait, 1950s."

🤖

LLM Enrichment Cloud

Large language models generate summaries, contextual descriptions, and metadata enhancements.

🔒

Content Flagging Cloud

Automatic detection of sensitive content. Flag for review before public access—protect your institution.

🎙️

Audio Transcription Edge

Whisper AI transcribes oral histories locally. Hours of interviews become searchable text.

🔍

Semantic Search Cloud

Find "photos of the old mill" even if no record mentions those words. AI understands meaning, not just keywords.

🔌

MCP Endpoints Soon

Model Context Protocol integration for smart, contextual searching. Connect AI assistants directly to your collection.

📦

Cloud Storage Cloud

Secure long-term storage with redundancy. Access your collection from anywhere, any device.

📤

Standards Export Cloud

Dublin Core, CSV, JSON, JSONL. Export your metadata in standard formats for downstream systems.
